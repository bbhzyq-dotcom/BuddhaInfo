# 佛教文化网站 - 项目概述

## 1. 项目背景

### 项目名称
**BuddhaInfo** - 佛教文化角色百科网站

### 核心目标
为用户提供一个便捷的佛教文化角色查询平台，收录佛、菩萨、罗汉、护法等角色的名称、简介和典故，支持浏览和搜索功能，并允许用户贡献补充数据。

### 目标用户
- 对佛教文化感兴趣的一般民众
- 研究佛教文化的学者和学生
- 导游、神职人员等需要查询佛教知识的专业人士

---

## 2. 功能概览

### 2.1 角色浏览功能
- **分类浏览**：按角色类型（佛、菩萨、罗汉、护法、 其他）分类展示
- **列表展示**：卡片式列表展示每个角色的基本信息（名称、头像/图片、简介）
- **详情页面**：展示角色的完整信息，包括：
  - 名称（中文名、梵文名、其他叫法）
  - 分类标签
  - 简介
  - 典故/故事
  - 相关经典出处

### 2.2 搜索功能
- **全文搜索**：支持按名称搜索
- **筛选功能**：按角色类型筛选
- **热门推荐**：首页展示热门/推荐角色

### 2.3 数据贡献功能
- **添加角色**：用户可提交新的佛教角色信息
- **补充数据**：用户可为现有角色补充典故、出处等内容
- **审核机制**：提交的数据需后台审核后可见

---

## 3. 数据范围

### 角色分类
| 分类 | 说明 | 示例 |
|------|------|------|
| 佛 | 佛教最高果位 | 释迦牟尼佛、阿弥陀佛、药师佛 |
| 菩萨 | 觉悟的有情 | 观音菩萨、文殊菩萨、地藏菩萨、普贤菩萨 |
| 罗汉 | 自觉者 | 十八罗汉、十六罗汉 |
| 护法 | 护持佛教的善神 | 韦陀菩萨、四大天王、伽蓝菩萨 |
| 其他 | 其他佛教角色 | 金刚、力士、夜叉 |

### 数据来源参考
- 维基百科佛教条目
- 《大正藏》等佛教经典
- 佛教在线、佛教百科等网站

---

## 4. 项目约束

### 技术约束
- 前后端分离架构
- 支持响应式设计，适配桌面和移动设备
- 数据库使用 SQLite（便于部署和迁移）

### 时间约束
- MVP 版本优先实现核心浏览和搜索功能
- 数据贡献功能作为第二阶段功能

---

## 5. 成功标准

1. 用户能在 3 次点击内找到任意角色的信息
2. 搜索响应时间 < 500ms
3. 页面加载时间 < 2s
4. 支持至少 500 个角色的数据存储
